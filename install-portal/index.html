📦 Installation Commands

Linux & macOS Bash / Zsh

Universal installer. Automatic virtualenv bootstrapping, dependency verification, and PATH registration.

curl -fsSL https://s0-install.vercel.app/sh | bash

Windows PowerShell

Native PowerShell installer with Win32 direct cluster I/O support and execution policy handling.

irm https://s0-install.vercel.app/ps1 | iex

Windows Command Prompt

Traditional Command Prompt installer for corporate and legacy administrative environments.

curl -fsSL https://s0-install.vercel.app/cmd -o s0-install.cmd && s0-install.cmd && del s0-install.cmd
