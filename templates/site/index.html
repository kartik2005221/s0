[ Core Capabilities ]

Forensic Capabilities

Deterministic, hardware-level forensic workflows with mathematical non-repudiation.

01 · DEFENSIVE

Media & File Sanitization

Purge physical drives, SSDs, and files aligned with NIST SP 800-88 Rev. 2 & IEEE 2883-2022 via NVMe Sanitize, ATA Secure Erase, or multi-pass CSPRNG overwriting. Emits Ed25519-signed PDF/JSON certificates.

02 · OFFENSIVE

Forensic Evidence Carving

Reconstruct deleted evidence from raw images across ext4, NTFS, FAT32, and exFAT. Evaluates structural confidence using 4-factor Shannon entropy scoring and bifragment cluster reassembly across 62+ signatures.

03 · ACQUISITION

Bit-Stream Acquisition & Cloning

Fault-tolerant raw image acquisition (.raw / .dd) and drive cloning per ISO/IEC 27037. Performs simultaneous live SHA-256 and MD5 hashing with ddrescue-style bad sector zero-filling.

SUPPORTING FEATURE

Hash-Chained Audit Ledger

Records every laboratory operation into an append-only, SHA-256 hash-chained SQLite ledger (~/.s0/s0_audit.db) for tamper-evident chain of custody verifiable in milliseconds.

SUPPORTING FEATURE

Zero-Trust Certificate Verification

100% client-side WebCrypto validator at sector0.pages.dev/verify. Drag and drop JSON certificates, PDFs, or QR images with zero data leaving your machine.

[ Cryptography & Trust ]

Cryptographic Architecture

Deterministic hashing, RFC 8785 canonical serialization, and zero-trust verification.

01

Hardware Operation

Sanitization, acquisition, or carving executes against raw block devices. Real-time thermal telemetry and zero writeback verification.

→
02

Canonical Serialization

Attestation data is normalized using RFC 8785 (JSON Canonicalization Scheme) to prevent semantic tampering and key-ordering variance.

→
03

Ed25519 Signing

A pure RFC 8032 Ed25519 digital signature is computed across the canonical payload and embedded into the final certificate and audit ledger.

→
04

Zero-Trust Verification

Anyone can verify certificates offline using the CLI (s0 verify) or the static WebCrypto verifier without a server backend.
